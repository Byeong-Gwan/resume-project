주요 프로젝트

1. BFF 응답 형식 변경 대응 (무중단 서비스 유지)
  • 배경: 백엔드 API 응답이 배열→객체로 변경되며 TypeError 다발, 무중단 대응 필요
  • 기술: Array.isArray() 검증, Promise 기반 예외 처리, 무중단 롤아웃
  • 결과: 서비스 오류율 0% 유지, 사용자 이탈 세션 15% 감소
  • 운영: 런북(원인→조치→테스트) 문서화, DataDog 로그로 상위 패턴 도출·Fallback 구현
2. 보안 대시보드(고객 보안 정보) 통합 개발
  • 배경: 분산된 보안 기능 단일 UI 통합, 월 50건+ "찾을 수 없다" VOC
  • 기술: 단일 JSON 응답, 비동기 병렬 호출, 로딩 상태 관리, CommonHelper.requestApi
  • 결과: 접근 경로 5단계→3단계(40% 개선), 보안 VOC 60% 감소(50→20건)
  • 효과: 사용자 만족도 개선, 리뷰 평점 상승 기여
3. 파일 업로드 검증 로직 강화
  • 배경: 대용량/비정상 확장자 업로드로 서버 부하·실패 VOC 발생
  • 기술: 3MB 제한, 확장자 화이트리스트, 총합 용량 검사
  • 결과: 비정상 업로드 100% 차단, 관련 VOC 전면 제거
  • UX: 사용자 친화적 에러 메시지로 경험 개선
