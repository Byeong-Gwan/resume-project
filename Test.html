주요 프로젝트

1. BFF 응답 형식 변경 대응 (무중단 서비스 유지)
백엔드 API 응답이 배열에서 객체로 변경되면서 TypeError 다발. 서비스 중단 없이 빠른 대응 필요.
기술: Array.isArray() 검증, Promise 기반 예외 처리, 무중단 롤아웃
  • 사용자 영향 없이 문제를 해결하며 운영 안정성 유지
  • DataDog로 에러 패턴을 정리하고 fallback 로직을 적용
  • 원인→조치 과정을 문서화해 재발 방지 체계를 마련
2. 보안 대시보드(Customer Security Info) 통합 개발
스팸차단, USIM 보호 등 분산된 보안 기능을 단일 UI로 통합. "찾을 수 없다"는 VOC가 반복적으로 발생.
기술: 단일 JSON 응답, 비동기 병렬 호출, 로딩 상태 관리, CommonHelper.requestApi 활용
  • 페이지 이동 흐름을 단순화하고 접근성을 개선
  • 복잡한 케이스별 분기를 정리하고 예외 처리를 보강
  • VOC 발생 원인을 정리하고 흐름을 단순화
3. 파일 업로드 검증 로직 강화
대용량 파일, 비정상 확장자 업로드로 인한 서버 부하 및 업로드 실패 VOC 지속 발생.
기술: 3MB 제한, 확장자 화이트리스트, 총합 용량 검사
  • 비정상 업로드를 사전에 차단하는 검증 체계 강화
  • 사용자 친화적 에러 메시지로 업로드 흐름 개선
